How To Run the code????
1. first clone the project..
2. Make a database Cluster in Mongo DB
3. Open Terminal
4. cd backend
5. then run command -->   "npm start"
6. similarly cd dashboard
7. run command ---> "npm start"
8. cd frontend
9. run command ---> "npm start"
10. first signUp from frontend
11. then login from frontend
12. then the dashboard will open
